# Project

This is a learning project for building a Bullet Journal web application
with Spring Boot.

## Tech Stack

- Java 17
- Spring Boot
- Gradle
- Spring Data JPA
- MySQL
- JUnit 5

## Learning Rules

- This project is for learning backend development.
- Do not implement an entire feature unless I explicitly request it.
- When I ask a question, explain the reasoning first.
- Prefer hints when I am trying to solve a problem myself.
- Do not introduce unnecessary frameworks or libraries.
- Keep implementations simple.

## Coding Rules

- Use constructor injection.
- Do not expose JPA entities directly from controllers.
- Use DTOs for API requests and responses.
- Prefer LAZY loading for JPA associations.
- Keep transaction boundaries primarily in the service layer.

## Testing

- Use JUnit 5.
- Run relevant tests after code changes.
- Do not modify tests just to make broken production code pass.

## Git

- Never commit or push unless I explicitly ask.
- Never rewrite Git history without explicit permission.
- Never commit passwords, API keys, tokens, or secrets.
